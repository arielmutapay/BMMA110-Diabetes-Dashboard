# BMMA110 Scenario 4 – Diabetes Health Indicators App

This is an interactive Streamlit version of the BMMA110 Scenario 4 analysis.

## Run it on a computer

1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

4. A browser window will open with the dashboard.

The app can automatically load the 2015 Diabetes Health Indicators dataset from the public GitHub mirror used for the analysis, or you can upload a populated CSV.

## Deploy online

You can upload these files to a GitHub repository and deploy `app.py` with Streamlit Community Cloud. Then you will get a normal web link you can open on your phone.

## Important

The uploaded CSV must be the populated dataset, not the blank selected-column template.
